# Final Project - Linux Server Health and Backup Automation

## Project Overview
Built a Bash automation tool to monitor Linux
server health and create compressed backups.

## Features
- Disk usage monitoring
- Memory monitoring
- Linux service status checks
- Timestamped logging
- Automated file backups
- Backup error handling
- Restore verification

## Skills Used
Bash variables, arrays, loops, functions,
conditions, exit codes, tar, systemctl,
df, free, date, tee, and Git.

## Main Script
server_automation.sh

## Output Location
~/bash-automation/

## How to Run
bash Day-40/server_automation.sh

## What I Learned
Combining individual Bash commands into
one reusable Linux administration tool.
