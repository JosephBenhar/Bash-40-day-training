# Automated Linux Backup and Restore

## What I Learned
Backups protect files against accidental deletion
and data loss.

## Important Commands
mkdir -p = Create directory
tar -czf = Create compressed archive
tar -xzf = Extract archive
date = Generate timestamp
ls -lh = List files with readable sizes
