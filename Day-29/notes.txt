DAY 29 - LINUX DISK MONITORING

1. df -h
Checks disk/filesystem space in human-readable format.

df = Disk Free
-h = Human readable

2. du -sh folder
Checks how much disk space a folder is using.

du = Disk Usage
-s = Summary
-h = Human readable

3. du -h --max-depth=1 ~
Shows disk usage one folder level deep.

DEPTH = folder levels, not file size.

4. sort -hr
Sorts human-readable sizes from largest to smallest.

-h = Human readable sizes
-r = Reverse

5. Find largest folders
du -h --max-depth=1 /home | sort -hr

6. Check root filesystem
df -h /

7. Extract disk usage percentage
df -h / | awk 'NR==2 {print $5}'

NR==2 = Line 2
$5 = Field 5

8. Remove the % symbol
df -h / | awk 'NR==2 {print $5}' | cut -d '%' -f 1

Example:
17% becomes 17

9. Store command output
disk_usage=$(df -h / | awk 'NR==2 {print $5}' | cut -d '%' -f 1)

$(command) = run the command and store its output.

MEMORY:
df = How full is my DISK?
du = Which FILE/FOLDER is using the space?
sort -hr = BIGGEST to SMALLEST

DAY 29 - PART 2: DISK MONITORING SCRIPT

Disk monitoring follows three steps:

COLLECT → DECIDE → REPORT

1. Collect real disk usage:

disk_usage=$(df -h / | awk 'NR==2 {print $5}' | cut -d '%' -f 1)

df = CHECK disk information
awk = PICK the usage percentage
cut = CLEAN the % symbol
$() = RUN the command
disk_usage = STORE the result

Example:
17% → 17 → stored in disk_usage

2. Check the warning threshold:

if [ "$disk_usage" -ge 80 ]

-ge = greater than or equal to

3. Decision:

If usage is 80 or higher:
Disk Status: WARNING

Otherwise:
Disk Status: Normal

TESTING:

17 >= 80 → FALSE → Normal
90 >= 80 → TRUE → WARNING

We can use a fake value such as disk_usage=90 to safely test
the WARNING condition without actually filling the disk.

MEMORY:

CHECK → PICK → CLEAN → STORE → DECIDE → REPORT
